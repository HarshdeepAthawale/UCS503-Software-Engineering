## 🎯 What to Lead With

1. **The problem is ghosting**, not discovery. Everyone builds discovery; almost nobody measures resolution.
2. **TTA is computed from immutable database timestamps** → accountability is structural, not social.
3. **Attestations require a completed application to exist** → verified competency cannot be farmed.
4. **The application budget** solves student spam and poster overload with a single constraint.
5. **Everything excluded** — no feed, no likes, no follower counts — is excluded on purpose.
